title: "Towards Verifiable-by-Design Smart Contracts: A Declarative Limit Order Books Implementation"
summary: A declarative approach to on-chain limit order books that treats correctness as a design constraint rather than an after-the-fact audit.
abstract: This paper introduces an on-chain limit order book built with a declarative smart contract language. By expressing conservation, ordering, and state-transition constraints directly, the design aims to make core properties easier to verify before deployment.
